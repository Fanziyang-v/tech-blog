## 为什么记录

技术学习中，真正值得留下的往往是解决问题的过程：最初的假设、失败的尝试，以及最终理解问题的那一刻。

一篇笔记可以从一个具体问题开始，再逐步写出分析、实现与结论。

## 代码示例

给代码块标注语言，就能获得语法高亮：

```python
def greet(name: str) -> str:
    return f"你好，{name}！"

print(greet("世界"))
```

## 组织文章

| 部分 | 建议记录的内容 |
| --- | --- |
| 背景 | 遇到了什么问题 |
| 分析 | 为什么会发生 |
| 实践 | 如何验证与解决 |
| 回顾 | 有哪些限制与改进空间 |

## 开始写作

在 `src/content/posts/` 中新增 `.md` 文件，填写标题、摘要、日期与标签。设置 `draft: true` 时，文章不会出现在构建后的站点中。

- 使用二级标题组织章节。
- 为代码标注语言。
- 为结论提供来源与适用条件。
